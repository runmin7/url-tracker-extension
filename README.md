# Web URL & Ajax 실시간 트래커 (Chrome Extension)

개발자 도구(F12) → Network 탭을 매번 열지 않고도, **버튼·메뉴·그리드 행 위에 마우스를 올리거나 클릭하는 즉시 이동 URL과 Ajax 호출 경로·파라미터를 확인하고 원클릭으로 복사**할 수 있는 크롬 확장 프로그램입니다.

---

## ✨ 주요 기능

### 1. 🌐 허용 도메인(Whitelist) 기반 선택적 활성화
- 기본적으로는 모든 사이트에서 비활성 상태로 대기하여 일반 웹 서핑을 방해하지 않습니다.
- 추적하고 싶은 웹사이트에 접속한 뒤 우측 사이드 패널을 열고 **`[+ 현재 사이트 허용 목록에 추가]`** 버튼을 한 번 누르거나 도메인(예: `example.com`, `*.example.com`, `localhost`)을 등록하면 해당 도메인에서만 트래커와 우측 하단 퀵 바가 활성화됩니다.

### 2. 🔍 마우스 오버(Hover) URL 미리보기 & 원클릭 복사
버튼, 메뉴, 링크(`<a>`), `DataTables` / `jqGrid` 목록 행 위에 **마우스를 올리기만 해도** 연결된 URL과 파라미터를 팝오버 툴팁으로 즉시 보여줍니다.
- **인라인 `onclick` 및 커스텀 JS 함수 자동 해석**:
  - `onclick="openDetail('2026001', 'KR')"` 처럼 커스텀 함수를 호출하는 경우, 페이지 `<script>` 내 함수 선언부를 역추적하여 **전달된 인자값을 실제 파라미터에 치환한 완성 URL**(`/app/orders/detail?docNo=2026001&orgCd=KR`)까지 미리 보여줍니다.
- **jQuery 이벤트 & DataTables / jqGrid 행 데이터 연동**:
  - HTML에 `onclick`이 없고 JS에서 `$("#btnSearch").on("click", ...)` 또는 위임(delegated) 이벤트로 바인딩된 버튼·테이블 행도 역추적하여 호출 예정인 Ajax / 팝업 / 이동 URL과 현재 입력 폼·행 데이터 파라미터를 추출합니다.
- **원클릭 복사 & `Alt + C` 단축키**:
  - 툴팁 내 **`[📋 URL 복사]`**, **`[🔗 전체주소]`**, **`[📦 파라미터]`** 버튼을 클릭하거나, 요소 위에 마우스를 올린 상태에서 **`Alt + C`**를 누르면 즉시 클립보드에 복사됩니다.

### 3. 🧭 크롬 우측 사이드 패널 (실시간 로그 & 4대 카테고리 필터)
버튼이나 메뉴를 실제로 **클릭**할 때 발생하는 모든 화면 전환과 비동기 호출을 우측 사이드 패널에 실시간 기록합니다.
- **카테고리별 탭 필터링**:
  - **전체** / **🚀 페이지 이동** (일반 링크, `location.href`, `form.submit`, `window.open` 팝업 포함) / **🖼️ IFRAME 전환** (`iframe` 내부 화면 전환) / **⚡ Ajax 호출** (`$.ajax`, `fetch`, `XMLHttpRequest`)
- **팝업창(`window.open` / `<form target="popup">`) 통합 추적**:
  - 새 팝업창으로 열리는 URL과 Form POST 파라미터는 물론, 열린 팝업창 내부에서 추가로 발생하는 이동/Ajax 호출도 메인 창의 사이드 패널로 통합 기록됩니다.
- **📌 로그 보관 (Preserve log) 옵션**:
  - 크롬 DevTools의 `Preserve log`와 동일하게, **체크 시** 화면 이동이나 새로고침 후에도 이전 로그를 계속 누적 기록하며, **체크 해제 시** 새로운 화면으로 이동할 때마다 이전 로그를 자동으로 리셋합니다.

### 4. 📊 우측 하단 와이드 퀵 바 (Quick Bar)
허용된 도메인 접속 시 화면 우측 하단에 가로형 퀵 바가 표시됩니다.
- **최근 감지/호버 URL 실시간 프리뷰** (클릭 시 즉시 클립보드 복사)
- **`🔍 호버 ON/OFF`** 원클릭 토글
- **`📌 로그보관 ON/OFF`** 원클릭 토글
- **`🚀 트래커 열기`** 버튼으로 우측 사이드 패널 즉시 오픈

---

## 🚀 설치 및 사용 방법 (Chrome / Edge)

1. 브라우저 주소창에 `chrome://extensions` (또는 `edge://extensions`) 입력 후 이동
2. 우측 상단 **개발자 모드(Developer mode)** 활성화
3. 좌측 상단 **압축해제된 확장 프로그램을 로드합니다(Load unpacked)** 클릭 후 프로젝트 폴더 선택
4. 추적할 웹사이트에 접속한 뒤 확장 프로그램 아이콘을 눌러 우측 사이드 패널을 열고 **`+ 현재 사이트 허용 목록에 추가`** 클릭

---

## ⌨️ 단축키 안내

| 단축키 | 동작 |
|--------|------|
| `Alt + C` | 현재 마우스를 올리고 있는 요소의 URL 즉시 복사 |
| `Alt + H` | 마우스 오버(Hover) URL 툴팁 표시 ON / OFF 전환 |
| `Alt + Q` (또는 `Alt + Shift + U`) | 우측 사이드 패널(URL 트래커) 열기 |
